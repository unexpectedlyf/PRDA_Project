# PRDA Profile Manager by Kgutlane Ralijeje

Node.js / Express / MongoDB / JWT application with HTML, CSS and JavaScript frontend. Login and profile pages follow the assessment specification; an additional registration page creates test users.

## Local setup
1. Install Node.js 20+ and MongoDB (local or Atlas).
2. Run `npm install`.
3. Copy `.env.example` to `.env` and set `MONGODB_URI` and a strong random `JWT_SECRET`.
4. Run `npm test` and `npm start`.
5. Visit `http://localhost:3000/register.html` to create a test account, then log in at `http://localhost:3000/`.
